## 一、核心功能模块：

1. 文件管理
   - 文件上传（支持CSV/Excel）
   - 文件历史记录查看
   - 数据集加载（从历史记录）
   - 文件预览（前100行）
2. **模型训练**
   - 算法选择（KDB/TAN/NB等）
   - 超参数设置（K值、root_node等）
   - 使用默认参数选项
   - 训练任务提交
3. **预测服务**
   - 单样本预测（表单输入）
   - 批量预测（文件上传）
   - 预测结果下载（CSV）概率，标签，评价指标等
   - 预测历史记录
4. **模型管理**
   - 模型保存/加载
   - 模型历史记录
   - 模型性能对比
   - 模型删除
5. **可视化**
   - 贝叶斯网络结构图
   - 条件概率表查看
   - 预测结果可视化

## 三、数据库设计（MySQL 为例，贴合 SQLAlchemy ORM）

### （一）设计原则

1. **实体关联清晰**：四大核心实体（文件、训练任务、模型、预测记录）建立合理外键关联，避免数据冗余
2. **软删除优先**：通过`is_valid`字段标记数据是否有效，避免物理删除导致历史数据丢失
3. **索引优化**：对高频查询字段（如`model_id`、`file_id`、`user_id`）建立索引，提升查询效率
4. **字段冗余合理**：核心性能指标（如`final_acc`）直接存储在模型表，避免关联查询开销
5. **兼容扩展**：预留`user_id`、`remark`等字段，便于后续扩展用户系统、添加备注功能

### （二）核心实体表结构设计

| 字段名         | 字段类型                                | 约束条件                            | 字段描述                            | 备注                                                         |

| `storage_type` | VARCHAR(20)                             | 'local'                             | 存储类型                            | 枚举：`local`（本地存储）/`minio`（MinIO 对象存储），兼容旧数据 |

| **索引**       | INDEX `idx_user_id` (`user_id`)         | 按用户查询文件历史                  |                                     |                                                              |
|                | INDEX `idx_upload_time` (`upload_time`) | 按时间排序查询                      |                                     |                                                              |

```sql
DROP TABLE IF EXISTS `file_info`;
CREATE TABLE `file_info` (
  `id` INT NOT NULL AUTO_INCREMENT COMMENT '文件唯一ID（主键）',
  `file_name` VARCHAR(255) NOT NULL COMMENT '文件名（含后缀，如dataset.csv）',
  `file_path` VARCHAR(512) NOT NULL COMMENT '本地存储路径 / MinIO对象名称（Object Name）',
  `file_bucket` VARCHAR(100) NOT NULL DEFAULT '' COMMENT 'MinIO Bucket名称（空字符串表示本地存储）',
  `storage_type` VARCHAR(20) NOT NULL DEFAULT 'local' COMMENT '存储类型：local-本地存储，minio-MinIO对象存储',
  `file_type` VARCHAR(10) NOT NULL COMMENT '文件类型：csv/excel',
  `file_size` BIGINT NOT NULL COMMENT '文件大小（字节）',
  `upload_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '文件上传时间',
  `user_id` VARCHAR(64) NOT NULL DEFAULT 'anonymous' COMMENT '用户ID（匿名用户默认anonymous）',
  `is_valid` TINYINT(1) NOT NULL DEFAULT 1 COMMENT '是否有效：1-有效，0-已删除（软删除）',
  PRIMARY KEY (`id`),
  INDEX `idx_user_id` (`user_id`) COMMENT '按用户ID查询文件历史',
  INDEX `idx_upload_time` (`upload_time`) COMMENT '按上传时间排序',
  INDEX `idx_storage_type` (`storage_type`) COMMENT '按存储类型筛选',
  INDEX `idx_file_bucket` (`file_bucket`) COMMENT '按MinIO Bucket筛选'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='上传文件信息表（存储数据集文件）';
```
